# 🇮🇳 Indian Sign Language Detection  

A web-based application for detecting Indian Sign Language (ISL) alphabets and numbers using a CNN-based machine learning model.

---

## 🔍 Overview

This project enables real-time detection of Indian Sign Language alphabets and numbers through webcam or image upload. It leverages a Convolutional Neural Network (CNN) built using TensorFlow and integrates the model with a user-friendly web interface using Flask.

---

## 🚀 Features


- 📷 **Real-Time Gesture Input**: Capture signs via webcam.
- 🖼️ **Image Upload Support**: Upload images for instant prediction.
- 🌐 **Web-Based Interface**: Built with Flask, HTML, CSS, and JavaScript.
- 📱 **Responsive UI**: Optimized for both mobile and desktop devices.
